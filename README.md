# 肥鱼账单 · dsh-fish-bill

> 给 [DSH](https://github.com/deepseek-ai) 的一个小插件：**只看你的 AI 搭子花了你多少钱。**
> 今天 / 本周 / 本月 / 累计，一张 14 天曲线，一个「投喂」按钮。
>
> 🔒 **不读聊天、不读微信、不连服务器，数据只存在你自己电脑上。** 详见 [PRIVACY.md](./PRIVACY.md)。

## 长什么样

```
🐟 大肥鱼账单
当前余额 ¥18.76   今天 ¥0.32   本周 ¥2.10   本月 ¥6.44
[最近 14 天柱状图]
累计 ¥12.80                              🐟 投喂大肥鱼
```

## 装法

1. 把 `dsh-fish-bill` 整个文件夹放进你的 profile：

```
C:\Users\<你>\.dsh\profiles\<profile>\vendor\dsh-fish-bill
```

2. 打开同级的 `package.json`，两处各加一行：

```json
"dependencies": { "dsh-fish-bill": "file:vendor/dsh-fish-bill" },
"dsh": { "profile": { "bundles": [ "…", "dsh-fish-bill" ] } }
```

3. **重启 DSH**（插件表只在启动时读一次）
4. 打开 `http://127.0.0.1:<端口>/dsh-fish-bill/`

> 装之前记得备份 `package.json`。bundles 里任何一项写错，桌面版可能起不来。

## 怎么算的

```
每 30 分钟记一次：{ 时间, 余额 }
花费 = 前一次余额 − 这一次余额（正数才算）
余额涨了 = 你充值了，不算花费
```

所以**装上的第一天没有历史**，从那天开始攒。想立刻记一次，面板上有「现在看一次」。

## 需要什么

- 一个能查余额的 DeepSeek 凭据：在 DSH 里登录过账号（设置 → 账号与余额）就行，
  或设环境变量 `DEEPSEEK_API_KEY`
- 没有 key 也能装，就是面板会提示

## 数据在哪

`~/.dsh/fish-bill/flow.jsonl` —— 删掉它账单就清零。

## 想加上「我自己的开销」？

普通版故意只做肥鱼——不用授权、不用配置、装上就能看。

想记自己的账，直接在面板「记一笔」里手动记就行，分类、统计、曲线都现成。
（曾经有过一个「读电脑微信自动记账」的进阶版，因为要自动化操作微信客户端、
既不实时又有合规风险，已经下掉不发了。）
